## ✨ Overview

The **BDOAA Problem Booklet** is an ongoing project to compile the problems of the **Bangladesh Olympiad on Astronomy and Astrophysics (BDOAA)** into a structured, accessible collection.

The present goal is to cover the **Regional and National rounds from 2018 through 2026**, preserving the development of the Olympiad while making earlier problems easier to study, teach from, and reference.

This repository is being developed collaboratively under the BDOAA organization. The current booklet initiative and compilation are being coordinated by **Fahim Rajit Hossain Shwadhin** ([GitHub](https://github.com/Rajit13), [ORCID](https://orcid.org/0009-0002-4699-8059)) together with BDOAA collaborators.

## 🎯 Project goals

- Collect BDOAA Regional and National round problems in one maintained archive
- Preserve problems from earlier editions of the Olympiad
- Standardize notation, formatting, figures, and references where appropriate
- Make the material easier to use for Olympiad preparation and instructor training
- Maintain a transparent Git/GitHub history for corrections and future editions
- Build a foundation that can later support indexing by topic, year, round, and difficulty

## 🧭 Current status

**Work in progress.**

The repository is currently being organized and the 2018–2026 problem archive is being assembled. Problems and metadata may be added gradually rather than all at once.

Until a formal release is tagged, files in the repository should be treated as development versions.

## 🤝 Contributing

Contributions that improve the accuracy and usefulness of the archive are welcome, especially:

- locating missing Regional or National round papers
- checking problem statements against original papers
- correcting transcription or LaTeX errors
- reconstructing diagrams at publication quality
- checking units, notation, and numerical constants
- improving indexing and metadata

### Suggested workflow

1. Fork this repository
2. Create a separate branch
3. Make your changes
4. Open a pull request with a clear description of the source and the changes made

When correcting an older problem, please identify the **year**, **round**, and **problem number** whenever possible.

## 🛠 Intended workflow

The booklet is expected to be maintained primarily with:

- LaTeX
- Git and GitHub
- source checking against original BDOAA papers
- reproducible figures and diagrams where practical
